# Changelog

## v0.0.2

### New Features

- **Settings system** — Configurable save directory for results via `~/.config/patternforge/settings.json`
- **First-launch setup** — Welcome screen prompts for save directory on first run
- **Settings screen** — Press `S` in the selection view to change the save directory at any time
- Results are now saved to the configured directory instead of the current working directory

### Improvements

- Help text updated with new keyboard shortcuts
- Save confirmation now shows the full file path

## v0.0.1

- Initial release
- Pattern selection, input, processing and results views
- Vi integration for editing/creating patterns
- Clipboard copy support
- Result save to file
